# Contributing

1. **Fork the repository**: Start by forking the repository to your own GitHub account.

2. **Clone the repository**: Clone your fork to your local machine.

   ```bash
   git clone https://github.com/YOUR-USERNAME/App-React-Native-Supabase.git
   ```

3. **Create a new branch**: Create a branch for each feature or bug fix.

   ```bash
   git checkout -b your-branch-name
   ```

4. **Commit your changes**:

   ```bash
   git commit -m "Your commit message"
   ```

5. **Push your changes** to your fork:

   ```bash
   git push origin your-branch-name
   ```

6. **Create a pull request** from your branch against the `main` branch of this repository.
